# 加工功能需求

## 1. 通用加工属性

### MACH-001 加工启用

用户必须能够决定图元是否参与加工。

### MACH-002 加工方向

用户必须能够设置或切换图元加工方向，并在画布上查看方向提示。

### MACH-003 加工起点

用户应能够为支持的图元指定加工起点。完整圆和完整椭圆默认从图元局部北极开始，正反向选择不得改变该起点。

### MACH-004 连续路径

相连图元形成的连续链或闭环应作为一个加工单元连续加工，不应在单元内部跳转到其他不相连图元。

### MACH-005 状态失效

影响几何或加工意图的操作发生后，旧排序结果必须失效；用户重新排序前不得将旧结果用于导出。

## 2. 三轴加工

### MACH-006 三轴排序

系统必须能够对已启用的平面加工图元生成加工顺序。

### MACH-007 距离优化

排序应减少不必要的空行程，同时保持连续路径内部的连接关系。

### MACH-008 方向与起点

三轴排序必须尊重用户设置的方向和起点，并将实际顺序显示给用户检查。

### MACH-009 不可加工图元

点和构造线不得进入三轴加工计划。

## 3. 方管截面

### MACH-010 截面识别

系统应从连续且严格闭合的真实图元边界识别方管垂直截面尺寸、圆角和截面中心。

### MACH-011 截面属性

方管截面数据包括 Y 方向尺寸、Z 方向尺寸、圆角半径和截面中心。截面中心使用 YZ 平面点 `(Ycenter, Zcenter)` 表示，默认值为 `(0, 0)`，即默认位于 X 轴上。系统必须显示并允许用户单独输入或修改四项截面数据。手动与自动来源优先级见[加工工艺需求](./machining-process.md)。

### MACH-012 倾斜断面来源

用户可使用垂直或倾斜的完整闭合断面作为识别输入；系统应根据其在方管截面方向上的真实边界确定尺寸、圆角和截面中心。

### MACH-013 圆角图元

圆角可由圆弧、椭圆弧或稳定曲率的多段线等受支持路径表达。只有可靠的整体边界才能用于截面识别。

### MACH-014 严格闭合

可测量的工程间隙不得被当作闭合。候选边界存在未连接间隙时，系统必须拒绝识别并显示实际间隙信息。

### MACH-015 位置稳定性

相同几何形状不应仅因远离世界坐标原点而得到不同的截面识别结果。

## 4. 内部线

### MACH-016 截面前置条件

内部线自动清理仅在方管截面尺寸、圆角和截面中心有效时运行。截面无效时系统应跳过清理并给出明确提示。

### MACH-017 内缩窗口

系统应在方管截面中心生成 YZ 平面内缩窗口：外轮廓四边按有效圆角半径内缩，存在多个有效圆角半径时采用最大值，并附加固定最小额外内缩，避免误删圆角区域图元。

### MACH-018 相交即删

直线、圆弧、圆、椭圆、多段线、轻量多段线和样条应按统一加工路径参与判断。路径 YZ 范围与内缩窗口相交（含接触）的图元整体删除，不拆分原始图元。

### MACH-019 窗口外保留

与内缩窗口不相交的图元保留。窗口坍缩时不得删除任何图元，并给出明确提示。

### MACH-020 不过滤

清理不按外轮廓成员、加工断面或废面角色过滤：与内缩窗口相交的图元全部删除。

### MACH-021 撤销恢复

一次自动清理作为单个撤销单元进入统一撤销栈，撤销后完整恢复全部被删除图元和对应加工状态。

### MACH-022 重复执行

自动清理可重复执行。已删除图元不再存在，后续清理按当前截面参数重新计算内缩窗口；同一图元不会被重复删除或重复排除。

## 5. 加工断面与废面

### MACH-023 加工断面

加工断面的自动识别、手动指定、智能闭环扩展、有效性判断、空间排序和工艺屏障均要求当前存在有效方管截面。加工断面必须是严格闭合、能够完整包围方管并在加工后形成工艺中断效果的真实路径或图元组。

### MACH-024 智能扩展

用户选择加工断面中的部分图元时，系统应从所选图元扩展到包含它们的唯一真实闭环，不要求用户逐条选全。

### MACH-025 混合边界

加工断面应支持由直线、圆弧、椭圆、多段线、轻量多段线或样条共同组成的闭环。

### MACH-026 自动识别

系统应能够识别场景中的有效加工断面，并允许用户恢复全部断面状态。

### MACH-027 工艺屏障

加工断面表示工艺顺序屏障：加工该断面前，其前方所属加工段内的普通加工内容必须先完成。

### MACH-028 多加工段

同一文件可包含多个方管加工段。多个加工断面按各自路径采样点的最小 X 升序加工，最小 X 相同时保留原有稳定顺序。断面之间不再通过 X 范围分离、双向侧别或相交检测决定先后；X 范围重叠或断面相交不会因此阻止排序。废面边界的相邻顺序使用同一规则。普通加工单元相对断面的侧别、废面过滤与断面自身有效性校验保持不变。

### MACH-029 废面

废面相关的截面空间判断要求当前存在有效方管截面。废面及按当前废面规则排除的相关加工内容不得进入加工排序和导出，但原始 CAD 图元必须保留。

### MACH-030 状态保护

加工断面和废面图元不得被自动内部线功能覆盖。

## 6. 方管四轴排序与轨迹

### MACH-031 普通四轴

普通四轴仅要求有效加工路径、旋转轴中心、XYZ/A 运动参数、当前有效加工顺序和配置。方管截面无效时，普通四轴排序、轨迹和 G-code 导出继续运行。

### MACH-032 截面增强四轴

截面增强四轴用于方管表面归属、圆角刀头方向、方管实体内部路径、加工断面、废面区间、真实工件碰撞边界和增强安全位置。以上功能要求有效的截面尺寸、圆角和截面中心；截面无效时应跳过或提示，不影响普通四轴继续运行。

### MACH-033 可选懒旋转工艺

懒旋转是截面增强四轴的可选工艺，要求当前存在有效方管截面。启用后，仅对位于方管四个平面上的普通加工组按表面集中排序，减少 A 轴往复旋转并保持约定的表面扫描方向；关闭后使用普通排序策略。

### MACH-034 连续组优先

跨多个表面的连续闭环或连续链形成一个加工单元，不得被表面分组或排序操作拆散。连续加工关系优先于单纯的表面扫描顺序。

### MACH-035 刀头方向

截面增强四轴加工方管平面时刀头应垂直于相应表面；加工圆角区域时刀头方向应随路径连续变化并指向对应圆角中心。截面无效时跳过依赖真实方管边界的圆角刀头方向计算。

### MACH-036 A 轴连续性

A 轴角度应连续展开，避免无意义的正负整圈跳变和加工连接处突然反转。

### MACH-037 安全移动

不连续加工组之间必须执行符合配置的安全移动；连续组内部不得插入无必要的抬刀。

同区位且 A 角不变的转移应支持可视化参数对话框。关闭联动时执行纯 Z 抬刀、XY 平移、纯 Z 落刀；开启时执行最小安全抬刀、联动抬刀、水平移动、联动落刀、最小安全落刀五阶段。两项最小高度相对各自端点，总高度不得小于其中较大值，默认自动取较大值，平移机床 Z 为较高端 Z 加总高度。联动抬刀和落刀水平占比默认各 25%，合计不得超过 100%，不允许反向折返。零高度联动段不占水平行程，零长度阶段合并。零总高度明确提示不离面。

预览、排序转移估算及最终输出应共用轨迹计算。对话框示例距离和端点 Z 差只影响示意图；确认后参数参与持久化，取消不修改配置。旧配置保留原同区离面高度，跨区位旋转和首次接近策略保持不变。修改配置应使原计划失效；同区位缓存轨迹若不符合当前参数，拒绝导出并提示重新排序。此预览仅验证参数化运动路线，不提供夹具或任意障碍物碰撞仿真。

### MACH-038 闭合回起点

闭合加工组完成一圈后必须精确回到起点。过切关闭时也必须完成闭合。

### MACH-039 过切

过切仅适用于闭合加工组，应沿原加工方向继续指定距离，并在关闭加工能量之前完成。

### MACH-040 初始位置

首个加工组的选择应独立考虑机床初始位置，避免加工开始即产生不必要的长距离移动或旋转。

## 7. 加工可视化

- 加工方向箭头和序号必须来自当前有效排序结果；
- 每个加工单元只显示一个加工顺序编号；
- 加工断面标签和顺序标签应保持可读且尽量少遮挡几何；
- 计划排除项应使用可区分的弱化显示样式；
- 用户关闭加工标记或排除显示后，状态仍应保留，并通过非阻塞消息提示。

## 8. 加工单元

### MACH-041 加工单元定义

一个连续加工组构成一个加工单元，不区分开放路径或闭合路径。与其他图元不连续的单个图元独立构成一个加工单元。

### MACH-042 加工单元成员

每个参与加工的图元只能属于一个加工单元。普通排序、智能排序和人工编排都必须以加工单元为最小单位，不得通过排序操作拆分加工单元。

### MACH-043 加工单元身份

加工单元身份由其全部稳定 `EntityId` 排序后的规范集合确定。加工单元身份不得使用 Viewer 对象地址、显示缓存键或成员在当前序列中的位置。

### MACH-044 方管厚度与激光内壁作用线

用户应能够设置供预览及加工断面修正使用的“方管厚度”，默认取有效方管截面的圆角半径；未手动修改时跟随已应用的圆角半径，手动修改后保留用户值。输入 0 恢复圆角半径默认值，替换文档时清除手动覆盖。圆角半径为 0 且没有手动厚度时，应提示用户设置大于 0 的厚度。

方管截面有效且加工断面标记可见时，系统应先将不同 CAD 图元统一编译为 `Path3D`，再按当前四轴配置逐点解算机床姿态和刀头方向。内截面 Y 长、Z 宽分别为外尺寸减去两倍壁厚，各内圆角半径为 `max(对应外圆角半径 - 壁厚, 0)`。厚度达到 Y 长或 Z 宽的一半、导致内腔消失时应报错，不显示两条走线。

绿色“激光内壁作用线”先从包含加工平面 Z 修正的刀头位置 S，沿单位刀头方向 D 取壁厚 t，得到候选点 `C = S + t*D`，再将 C 的 YZ 坐标按最近点投影到内截面轮廓，保持其 X 坐标，得到作用点 E。最终显示应受内轮廓约束；A 轴反向、A 轴角度偏置、旋转轴中心和 Z 修正参与候选点计算，但不得让投影离开内轮廓。仅沿内轮廓法向的位移可能被投影抵消。

相邻采样点跨越内直角时应补入准确的转折点，闭合段也应处理，禁止直接斜连穿过内腔。壁厚大于或等于外圆角半径时，内圆角应退化为直角，YZ 投影以直线段相接，不形成负半径反向弯曲。壁厚小于外圆角半径时保留真实内圆角。此功能仅是内截面投影预览，不是激光射线与材料的完整求交仿真；不改变原始 CAD 图元、加工状态、排序、机床轨迹或 G-code。

### MACH-045 期望断面内侧走线与独立显示

系统应按加工断面汇总统一路径的采样点，根据其 YZ 位置识别四个圆角，仅使用各圆角自己的采样点分别求局部断面方向。相差不超过 1° 的方向合并，最多允许两个方向；圆角局部拟合的 X 残差不得超过 0.01 mm。禁止将完整加工断面的采样点拟合为单个目标平面。

圆角之外的边（包括曲线）应继承两端圆角的共同方向，以每个原始采样点为局部锚点。边两端的方向不一致属于工程数据错误，应明确指出断面和对应边，停止显示该断面的期望走线，不插值、不强行合并。缺少圆角采样、圆角退化或无法可靠拟合时也应提示原因；其他有效断面及激光内壁作用线不受影响。

期望点应保持与投影后的激光内壁作用点相同的 YZ 位置，根据局部断面方向求 X。若局部方向为 `x = a*y + b*z + c`，源采样点为 P、内壁作用点为 E，则期望点 Q 满足 `Q.y = E.y`、`Q.z = E.z`、`Q.x = P.x + a*(E.y-P.y) + b*(E.z-P.z)`。期望线也须补入内直角转折点，并用局部断面方向修正新增点的 X，保持两条线具有相同 YZ 投影。两条线共用方管厚度参数；斜向的 P 到 Q 距离可以与壁厚不同。该走线仅是内轮廓上的期望断面参考，不代表完整材料加工仿真。

加工设置应提供独立的“激光内壁作用线（绿色）”和“期望断面内侧走线（紫色）”显示开关。开关即时影响画布且保留方管厚度，均受加工标记和加工断面标记总开关控制。壁厚、截面、原始图元或四轴配置变化时应重建预览。显示开关不修改原始图元、加工状态、排序、实际刀路及 G-code；导出修正由 MACH-046 的独立工艺开关控制。

### MACH-046 加工断面正向与反向修正

加工设置应提供独立的“加工断面正向修正（+X）”与“加工断面反向修正（−X）”开关，默认均关闭，可同时开启。选项为当前运行期间的导出设置，不写入设备配置。

仅对四轴加工计划中标记为加工断面（Break）的路径生效。路径离散完成后，按当前方管厚度、四轴姿态及加工平面 Z 修正求内壁投影作用点，并使用 MACH-045 的圆角方向算法求原始期望点。令差值为 `期望点.X - 内壁作用点.X`：正向开启时只应用正差值，反向开启时只应用负差值，直接加到源加工路径的 X；Y、Z 和路径顺序保持不变。期望点仅根据未修正路径计算一次，避免重复修正移动目标。

修正后的路径进入四轴解算、闭合、过切和空移计算，再生成 G-code。失效的原空移签名应重新计算；原始 CAD 图元及计划排序保持不变。两种修正均关闭时保持原输出，普通加工单元不应用此修正。显示开关与工艺开关独立，画布保留未修正的两条参考走线。

开启修正但断面标记、方管截面、壁厚或期望方向无效时，应明确报错并停止导出，不静默输出未修正路径。该工艺对齐的是现有内截面投影点，不是完整激光与材料求交仿真。
