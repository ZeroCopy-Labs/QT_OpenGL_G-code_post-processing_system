# 方管四轴

## 1. 适用范围

四轴加工仅适用于绕 X 轴回转、由 A 轴表示周向旋转的当前加工场景。

普通四轴使用：

- 有效加工路径；
- 旋转轴中心；
- XYZ/A 运动参数；
- 当前加工计划和 G-code 配置。

方管截面有效后可增加：

- 方管表面和圆角归属；
- 内部线清理；
- 加工断面和废面；
- 懒旋转区位扫描；
- 真实工件边界参与的安全计算。

## 2. 识别方管截面

1. 选择一个严格闭合截面，或选择其外围边界中的一条图元。
2. 点击“机加工 → 识别方管截面”。
3. 在右侧“方管识别状态”检查 Y 长、Z 宽、圆角半径和识别状态。

候选边界必须真实连续并严格闭合。辅助构造线、内部支线和未连接间隙会影响识别。

自动识别不适合当前文件时，可在右侧输入 Y 长、Z 宽和圆角半径，再点击“应用手动截面”。

## 3. 清理内部线

内部线清理仅在方管截面有效时执行。点击一次“清理内部线条”，系统自动完成以下步骤：

1. 在截面中心生成 YZ 平面内缩窗口：外轮廓四边按最大圆角半径内缩，并附加额外安全内缩；
2. 选择路径 YZ 范围与窗口相交（含接触）的图元；
3. 物理删除选中图元，删除作为单个撤销单元进入撤销栈，可按 Ctrl+Z 整体恢复。

与窗口不相交的图元保留；清理不按外轮廓成员或断面角色过滤。圆角半径过大导致窗口坍缩时不会删除任何图元。

清理后可直接重新排序；截面一经识别或手动设置即持续有效，几何变化不会使其失效。清理可重复执行，已删除图元不会再次参与。

## 4. 加工断面

加工断面要求：

- 已有有效方管截面；
- 候选图元形成严格闭合边界；
- 边界能够完整映射到方管外表面；
- 加工后形成明确的工艺中断。

可选择断面的一条边，让系统扩展完整闭环。加工断面作为工艺屏障，其前方加工段内的普通加工单元先完成，然后加工断面。

多个断面仅按路径最小 X 从小到大排序，越小越先加工；最小 X 相同时保持原有稳定顺序。断面之间的 X 范围重叠或相交不再作为排序失败条件。普通加工单元跨越断面等检查仍保留。

右侧“方管识别状态”中的“方管厚度”用于查看加工断面的两条内侧参考走线。厚度默认等于圆角半径，未手动修改时随已应用的圆角半径更新；手动修改后保留用户值。输入 0 可恢复默认值，替换文档后也恢复默认。圆角半径为 0 时，需要手动输入大于 0 的厚度。可分别勾选：

- “激光内壁作用线（绿色）”：不同图元先统一转换为路径，再按当前四轴配置逐点解算刀头姿态；从含 Z 修正的刀头位置沿刀头方向取一个壁厚的候选点，再将其 YZ 位置投到内截面轮廓，保留 X。它是投影预览，不是射线与材料的完整求交仿真。
- “期望断面内侧走线（紫色）”：只根据四个圆角自己的采样点推断方向，再将共同方向赋予相邻边。曲线边保留各点的原始形状，以当前点为基准，在与绿色作用线相同的内轮廓 YZ 位置求出期望的 X 位置；两条线的 X 差异可用于观察断面偏差。

内截面尺寸等于外尺寸减去两倍壁厚，内圆角半径为 `max(外圆角半径 - 壁厚, 0)`。壁厚达到或超过外圆角半径时，两条线的 YZ 投影沿直角内轮廓以直线段相接，不再在圆角处反向弯曲；跨边时会自动补入转折点，避免斜连切过内腔。壁厚小于外圆角半径时保留内圆角。若壁厚达到 Y 长或 Z 宽的一半，内腔已消失，系统会提示错误并暂停两条走线。

两条走线共用方管厚度，都计入当前四轴配置和加工平面 Z 修正，独立开关不会清空厚度。“走线状态”显示可预览的断面数量和失败原因。边两端的圆角方向不一致会明确报工程数据错误，不做过渡，也不显示该断面的期望走线；激光内壁作用线仍可查看。无圆角、圆角采样不足或圆角本身无法拟合局部方向时同样提示原因。

隐藏走线请使用各自的显示开关，或“加工标记”和“加工断面标记”总开关。显示开关不影响导出工艺。

生成四轴 G 代码时，可独立开启“加工断面正向修正（+X）”和“加工断面反向修正（−X）”，默认均关闭：

- 正向：期望点 X 大于内壁作用点 X 时，将对应加工点沿 +X 移动差值。
- 反向：期望点 X 小于内壁作用点 X 时，将对应加工点沿 −X 移动差值。
- 同时开启：补偿全部有符号差值；同时关闭：恢复原输出。

修正使用当前方管厚度及 Z 修正，仅作用于加工断面，不改变普通加工单元和 CAD 原始图元。闭合、过切和空移根据修正后的路径生成。画布仍显示原始作用线与期望走线以便比较；隐藏走线不会关闭修正。若壁厚或期望方向无效，会报错并停止导出。两个工艺选项保留于当前运行期间，不保存到设备配置。

废面及其影响范围不会进入计划和导出，但原始 CAD 图元保留。

## 5. 懒旋转

懒旋转是可选的截面增强工艺。启用后：

- 按方管区位组织普通加工单元；
- 在约定周向和轴向扫描方向下加工；
- 减少无必要的 A 轴往复旋转；
- 连续链和闭环仍作为完整加工单元，不会被区位扫描拆散。

加工单元无法确定唯一稳定区位时，系统会拒绝生成不安全计划。应检查截面、重复图元、连续关系和路径是否位于支持的表面区域。

## 6. 运动安全

### 旋转安全抬刀距离

跨区位或发生 A 轴旋转时，刀头高于工件旋转包络的安全余量。

### 同区空移离面距离

同一区位加工单元之间空移时的离面距离。设置为 0 时使用贴面转移。

### 联动转移

启用后，系统在安全约束下协调离开、旋转和接近过程。该选项不会放宽连续性或碰撞检查。

### 过切

闭合加工单元先精确回到入口，再沿原方向继续指定距离。设置为 0 时关闭过切。

### 加工面 Z 修正

对四轴加工面位置施加统一补偿。修改后应重新生成轨迹并检查最终安全位置。
