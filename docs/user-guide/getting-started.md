# 快速开始

## 1. 启动准入

程序启动时会先校验程序目录下的 `license.dat`：

- 有有效授权：正常进入主界面；
- 没有有效授权：直接弹出“需要授权”对话框（显示授权状态、当前机器码和程序目录），关闭对话框后程序结束，不会进入主界面；对话框中的“复制机器码”可复制机器码；
- 获取授权：把机器码发给软件提供方，取得 `license.dat` 后放到 `G-code_post-processing_system.exe` 同目录，再重新启动；也可在命令行执行 `G-code_post-processing_system.exe --license-request`，程序目录会生成 `机器码.txt`；
- 授权只区分“已授权”和“未授权”：取得有效授权后即可使用全部功能。

## 2. 界面区域

界面分为两个一级工作区，用主视口右侧窄轨道上的 **CAD / CAM** 大按钮切换，两者共用同一个绘图视口和同一份 CAD 文档，切换不重新导入文件：

- 点击按钮切换；鼠标位于该轨道内时滚轮向上 / 向下切换工作区；键盘使用 **Ctrl+Tab** 与 **Ctrl+Shift+Tab**。
- 滚轮只在轨道范围内切换工作区，鼠标在三维视口上时仍是缩放等导航操作。

- **CAD 工作区**：文件（文件导入）、绘图、修改、整理（去重）、图层、特性和画布显示（背景网格）。用于创建、修改和整理几何。
- **CAM 工作区**：加工面板按阶段分为三个页签。
  - **规划**：截面与断面（识别方管截面、加工设置、清理内部线条、识别加工断面）、排序（保留方向、智能排序）和加工显示（显示机加工相关、加工方向箭头、加工顺序编号、加工断面标记、废弃区域弱化、恢复默认显示）。
  - **仿真**：准备仿真、播放、暂停、单步、复位，以及播放倍率、进度和当前运动状态显示；仿真只回放已算出的机床运动，不修改几何和加工计划。
  - **NC 与后处理**：G代码导出、当前配置、G代码模式和 G代码配置。
- **“机加工”菜单**（仅 CAM 工作区显示）：按方管四轴工作流分组——截面（识别方管垂直截面、应用手动截面）、内部线（清理内部线条）、加工断面（指定、废面、识别所有、清除）、排序与方向（保留方向、智能排序、反向加工）、导出（导出 G 代码）。
- **“编辑”菜单**（仅 CAD 工作区显示）：镜像、偏移、阵列、修剪、延申、合并、圆角、倒角等几何编辑。
- **“文件”“视图”“用户设置”“帮助”菜单**：两个工作区共用。
- **右侧加工设置**（仅 CAM 工作区显示）：导入后自动处理、导出习惯、方管截面状态与参数。

首次进入 CAM 工作区时加工设置默认显示；在 CAM 中关闭面板后保持关闭，切换到 CAD 再返回 CAM 会按上次的选择恢复，重新启动程序同样恢复上次的选择与面板宽度。面板关闭后仍可通过加工面板中的「加工设置」按钮、机加工菜单或视图菜单重新打开。
- **底部状态区**：坐标、捕捉、正交、极轴追踪和命令提示。
- **画布右上角视图方块**：切换顶、底、左、右、前、后等标准视角。

进入 CAD 工作区时画布只显示几何，加工方向、编号和断面标记等加工可视化暂停显示，返回 CAM 工作区时恢复。

## 3. 打开文件

1. 使用“文件 → 导入文件”，或将 DXF/DWG 文件拖入画布。
2. 最近成功打开的文件可从“文件 → 最近打开”再次打开。
3. 导入完成后检查图元数量、位置、图层和曲线形状。
4. 需要清理完全重叠图元时，使用 CAD 工作区“整理”中的“去重”。

导入后自动去重、自动识别方管截面等选项位于右侧“加工设置”。自动处理失败不会撤销已经成功读取的文件，应根据命令栏提示继续检查。

## 4. 平面三轴流程

```text
导入或绘制
→ 检查并编辑图形
→ 选择 3轴 模式和当前配置
→ 设置加工方向或起点
→ 普通排序或智能排序
→ 检查加工单元编号和箭头
→ 导出 G-code
```

## 5. 方管四轴流程

普通四轴可直接使用有效路径、旋转轴中心和运动配置：

```text
导入和检查
→ 选择 4轴(绕A)
→ 设置运动安全和四轴参数
→ 排序
→ 检查 XYZ/A 方向
→ 导出 G-code
```

需要表面归属、圆角方向、内部线、加工断面或懒旋转时：

```text
识别或手动设置方管截面
→ 清理内部线
→ 识别或指定加工断面
→ 设置截面增强工艺
→ 重新排序并检查
→ 导出 G-code
```

## 6. 导出前检查

- 当前模式与目标机床一致。
- 当前配置中的旋转轴中心、方向和安全距离正确。
- 加工编号连续，方向箭头符合预期。
- 内部线已清理，废面和加工断面状态正确。
- 闭合路径完整回到入口，需要时包含过切。
- 不连续加工单元之间存在安全转移。
