# 加工排序与导出

## 1. 加工单元

连续开放链、连续闭环和独立图元都以加工单元参与排序。每个加工单元：

- 在执行序列中保持连续；
- 只显示一个加工编号；
- 只显示一个实际起点方向箭头；
- 编号由当前序列位置连续生成；
- 导出的 G-code 中，单元内非首成员不插入快速定位，切削连续接续上一成员终点；单元之间保留安全转移。

## 2. 两种排序

### 排序（保留方向）

普通排序尽量保留：

- 当前仍有效加工单元的相对顺序；
- 人工方向；
- 人工起点。

新增、拆分或合并后形成的新单元按当前自动计划补入。

### 智能排序

智能排序重新计算全部加工单元的：

- 顺序；
- 实际方向；
- 实际起点。

本次计算忽略当前单元序列以及人工方向、起点，但不会删除已经保存的人工状态。加工断面和废面等工艺状态继续生效。

### 重复图元

排序属于加工规划，不会删除 CAD 图元。发现完全重复的几何（类型、颜色和路径都相同）时，第一个图元参与加工，其余图元在本次加工计划中按“重复几何”排除，命令栏会提示排除数量；CAD 图元仍然存在，文档内容和撤销历史都不变化。

需要真正删除重复图元时，使用 CAD 工作区“整理”中的“去重”，或导入后的自动去重选项。

## 3. 标签和箭头操作

- 单击编号：只选择该加工单元的全部成员。
- `Shift + 单击编号`：追加或取消整个加工单元。
- 双击编号或箭头：反向整个加工单元。
- 选中一段编号连续的加工单元后，`Ctrl + 单击编号`：将目标单元移动到该范围末尾。
- `Ctrl + 框选`：框中命中任一成员时选择完整加工单元。
- `Ctrl + Shift + 框选`：按完整加工单元增量切换。

块内移尾要求选择范围编号连续，目标必须属于该范围。操作可通过统一 Undo/Redo 恢复。

## 4. 计划失效

以下变化会使旧排序失效：

- 新增、删除或修改几何；
- 修改加工启用、方向或起点；
- 修改内部线、加工断面或废面；
- 修改方管截面；
- 修改加工单元序列或遍历；
- 切换影响规划的加工模式或工艺。

失效后重新执行普通排序或智能排序。

## 5. G-code 配置

CAM 工作区 **NC 与后处理** 页签的“G代码配置”框用于选择当前配置和 G-code 模式：

- **当前配置**：管理配置文件与检索路径，右侧下拉框快速切换当前配置；
- **G代码模式**：自动、3轴或 4轴(绕A)；
- **G代码配置**：设置文件、图层、颜色、图元类型代码规则，以及运动安全和四轴参数（“用户设置”菜单中也有“G代码配置...”入口）；
- **加工设置**：位于 CAM 工作区 **规划** 页签，打开右侧面板设置导入后自动处理和导出路径习惯，并显示方管截面状态。

点击 G-code 配置对话框的“确定”后，运动安全和四轴参数会保存到本机设置；点击“取消”不会保存。

## 6. 导出

1. 先在 CAM 工作区完成排序，生成当前有效的加工计划。
2. 确认当前 G-code 模式。
3. 确认当前配置和机床参数。
4. 检查编号、箭头、排除状态和加工断面。
5. 点击“G代码导出”并选择目标文件。

导出只消费已有结果，不会自动排序或建立几何快照。没有加工计划时提示“当前没有有效的加工计划，请先完成 CAM Planning。”；计划或几何快照已失效时提示重新执行 Planning。任一必要阶段失败时停止导出，不写出部分程序。
